# NiuEnhance 开发路线

## V0.1 基础与只读诊断
- [x] 单 APK + legacy LSPosed 入口及小牛 5.19.0 白名单
- [x] Android 16 / 一加15 的媒体控制与蓝牙已配对设备检测
- [x] 独立驾驶舱、LSPosed 心跳检测、安全失败回退
- [x] GitHub Actions Debug 构建、固定签名 Release 配置
- [ ] 实机测试并验证 CI（代码提交不等于已通过编译）
- [ ] 获取官方 APP 5.19.0 的页面控件结构，再启用安全 UI 精简

## V0.2 页面增强
- [x] 实机确认「我的」页面为原生 View 控件（250 节点）
- [x] NIU ZOO、我的小队独立开关默认关闭；安全容器匹配失败时不隐藏
- [ ] 实机测试标签容器是否正确匹配，若跳过再针对具体控件做精细适配
- 仅对验证过的 5.19.0 View 路径启用 NIU ZOO / 我的小队等可选隐藏
- 原厂车况页非侵入式增强入口，版本不匹配自动关闭
- 设置项通过最小权限的跨进程 Provider 同步

## V0.3 蓝牙与电池
- 每设备 A2DP / GATT 只读状态探测、连接时间线
- 可选 ANT BMS 独立数据源，来源与官方 SOC 明确区分

## 边界
不修改车辆解锁、制动、TCS、动力、遥控、OTA、蓝牙钥匙。
完整投屏不在本项目当前范围内。
