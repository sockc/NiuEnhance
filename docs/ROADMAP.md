## V0.3.1 声音增益实验
- [x] 数字测试音分级 -13/-7/-4 dBFS
- [x] 支持本地音频的 MediaPlayer + LoudnessEnhancer（限定 +6 dB）
- [ ] 一加15配合 FX 测试增益对同一首歌的实际响度影响
- [ ] 若增益提升很有限，转向原车功放与车机设置排查

## V0.3.0 声音专项
- [x] 媒体音量/静音状态/预期音频输出设备只读诊断
- [x] 标准媒体链路 440Hz、3秒固定低电平测试音，需用户停车后主动触发
- [ ] 一加15连接 FX 蓝牙后的实机声学对比
- [ ] 根据测试结果决定是否研究播放器音频会话级 LoudnessEnhancer；不承诺突破车辆功放输出上限

## V0.2 页面增强
- [x] V0.2.2：开关变化后立即显示待应用状态，不再用过期页面快照误判开关是否生效
- [x] 实机确认「我的」页面为原生 View 控件（250 节点）
- [x] NIU ZOO、我的小队独立开关默认关闭；安全容器匹配失败时不隐藏
- [ ] 实机测试标签容器是否正确匹配，若跳过再针对具体控件做精细适配
- 仅对验证过的 5.19.0 View 路径启用 NIU ZOO / 我的小队等可选隐藏
- 原厂车况页非侵入式增强入口，版本不匹配自动关闭
- 设置项通过最小权限的跨进程 Provider 同步

## V0.3 蓝牙与电池
- 每设备 A2DP / GATT 只读状态探测、连接时间线
- 可选 ANT BMS 独立数据源，来源与官方 SOC 明确区分

## 边界
不修改车辆解锁、制动、TCS、动力、遥控、OTA、蓝牙钥匙。
完整投屏不在本项目当前范围内。
